# Website Blocker

A Windows website blocker built with C# and .NET.

## Features

- Add websites to a blocklist
- Remove websites from the blocklist
- Enable/disable blocking
- Block websites across browsers
- Persistent configuration
- Windows background service
- Logging
- Domain matching
- Unit tests

## Technologies

- C#
- .NET
- WPF
- XAML
- JSON
- Windows Services
